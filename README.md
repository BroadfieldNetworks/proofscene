## Official public repository

This is the official public repository for [ProofScene](https://proofscene.com/), 3D print proofing and
artwork approval software from [Broadfield Networks LLC](https://broadfieldnetworks.com/). It provides
verified product, demo, tool, support, and community links. ProofScene source code is maintained privately.

## What ProofScene does

- Turns proof-sheet PDFs into interactive 3D proofs of cards, packaging, lanyards, wristbands, and other printed products.
- Shows materials and finishes such as foil, raised UV, metallic ink, holograms, lamination, chips, and magnetic stripes.
- Publishes browser-based proof links that customers can rotate, inspect, and review without installing an app.
- Keeps jobs in a searchable proof library and supports branded company proof links.
